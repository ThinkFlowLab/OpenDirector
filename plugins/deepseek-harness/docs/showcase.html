Ready to try it?

Start with one image or one short voiceover.

  1. Start OpenDirector and add a model under Settings → Model connections.
  2. In DSH, open Plugins → Add plugin and enter the local .tgz path from your Release or PR artifact. Enable OpenDirector.
  3. Choose Create media. Try an example, select your model and generate a candidate.

先启动 OpenDirector 并配置模型，再在 DSH 安装插件。从「创作素材 → 试一个例子」开始。
