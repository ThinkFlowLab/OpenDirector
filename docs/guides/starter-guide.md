# Interactive starter guide / 交互式入门向导

From the first-run welcome or Help, choose **Start / resume exercise**. The guide imports an independent three-shot basketball project. Existing projects are saved before switching; the sample never overwrites them. Resume returns to the remembered project, while **New exercise copy** explicitly creates another project with a unique name.

从首次欢迎页或帮助中选择「开始 / 恢复练习」。向导创建独立的三镜头篮球练习项目，切换前保存已有项目，不覆盖作品。「新建练习副本」明确创建另一个不重名的项目。

1. Edit and save the story and shot text / 编辑并保存故事、镜头文字。
2. Inspect the character reference and create a real reference relationship / 查看角色参考，建立真实参考关系。
3. Choose an authored keyframe composition / 选择原创关键帧构图。
4. Add the three bundled clips to the timeline / 将三段预制视频加入时间线。
5. Open the normal timeline editor, reorder or trim, preview, and export / 打开正常时间线编辑器，调整顺序或裁剪，预览并导出。

These are original authored illustrations, **not AI inference** or the README's original film. Editing prompts and choosing a keyframe do not regenerate the clips. There are no model calls or keys in this flow. See the bundled `public/starter-guide/README.md` and manifest for provenance. The silent animation is intentionally small; shot 2 is a held composition. The normal browser export prerequisites still apply. The reference cut is not substituted for the user's export.

素材为原创程序绘制的插画动画，**不是 AI 推理结果**，也不是 README 中的原片。改提示词或选关键帧不会重新生成预制视频。本流程无需 Key、不调用模型。来源见素材包 README 与清单。样片无声，第二镜为静态构图。导出仍须满足正常浏览器能力要求；不以参考成片代替用户导出。

Project content is authoritative on the server. Guide position, visibility and last sample-project identity are browser navigation hints only. Clearing browser storage loses these hints, not project edits; open the sample project and use Help to resume. Skipping leaves the project intact. No completion claim is made before the user exports and checks the file.

项目内容由服务端保存；步骤、显示状态和最近练习项目 ID 只是浏览器导航提示。清理浏览器存储不会删除项目，打开练习项目后可从帮助恢复。跳过保留项目。向导不会在用户实际导出并检查文件前声称已完成。
