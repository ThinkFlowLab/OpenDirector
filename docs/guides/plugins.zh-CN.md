# 可选创作插件

[English](plugins.md)

插件向现有助手引擎提供可选的创作技能。打开 **设置 → 插件**，安装插件包，
再选择允许使用它的引擎。安装后默认全部关闭。同一个包可以支持默认引擎、
OpenCode、Codex、Claude Code、JiuwenSwarm 和 DeepSeek Harness；切换引擎后，
技能列表只显示该引擎已启用的插件。

这里的格式是 OpenDirector 技能包，包含一个原生 Skill 入口及配套模板或脚本。
它与让外部 DSH 调用 OpenDirector 的 [DSH 接入包](../../plugins/deepseek-harness/README.zh-CN.md)
不同；其他引擎的原生插件格式不能直接作为此类包安装。

## 安装与使用

1. 在 **设置 → 插件** 中安装官方「创作简报」，选择 ZIP 文件，或输入本地目录、
   ZIP 路径、公开 HTTPS ZIP 下载地址。路径指运行后端的计算机。只安装可信来源。
2. 在「启用的引擎」中勾选需要的引擎。依赖必须先安装指定版本，并在同一引擎启用。
3. 在助手中选择对应引擎，打开「技能」，选择插件，再用中文或英文描述目标。
   模型配置及引擎登录沿用现有设置。
4. 检查工程中的实际产物。官方「创作简报」读取工程上下文，整理简报与分镜，
   发布为可编辑的 Markdown 文本素材；它自身不发起图片或视频生成。

应用只附带官方发现目录。示例包在明确安装时下载；源码环境可使用对应的本地示例。
可选插件不会自动启用或进入默认技能目录。安装仅校验并保存文件，不执行安装钩子。
启用后，技能指令和脚本使用引擎已有工具、权限和工程业务命令；安装不会授予额外权限。

## 停用、卸载与升级

变更从后续对话轮次生效。已接受的任务保留自己的技能快照。启用的插件集合变化后，
后续轮次使用已保存的对话历史启动新的原生会话，不继续复用旧插件上下文。
如果尚未发送的消息选中了已停用技能，请先移除；后端会拒绝不可用的技能选择。

先停用依赖此插件的其他插件。更新版本时，停用并卸载旧包，安装新包，再启用需要的引擎。
重复安装相同内容会保留启用状态；同一 ID 的不同内容必须先卸载旧包。依赖采用精确版本，
不支持版本范围，也不会自动下载依赖或更新。

登记文件和不可变包缓存位于后端工作目录的 `.opendirector/plugins/`，重启后保留，
对该工作目录下的项目生效。卸载移除登记及后续发现入口，为进行中的任务保留包缓存，
不自动清理缓存。工程素材、生成配置、对话历史与执行回执仍保存在统一工程中；
停用或卸载插件后可以继续编辑。
缓存包损坏时，可以卸载后从有效来源重新安装。重装会先将损坏缓存保留到
`.opendirector/plugins/.damaged-*`，再发布校验通过的新副本，不删除旧文件。

## 制作自定义插件

复制 [plugins/template](../../plugins/template)，修改 ID、中英文名称和说明、支持的引擎与技能指令。
以下三个位置的身份必须一致：

```text
opendirector-plugin.json → id: my-creative-tool
skills/my-creative-tool/SKILL.md → name: my-creative-tool
```

清单要求 `schemaVersion: 1`，最长 64 字符的小写连字符 ID，`major.minor.patch` 版本
（可带预发布后缀），`zh-CN` 和 `en-US` 名称与说明，以及至少一个引擎 ID。
可用引擎 ID 为 `default`、`opencode`、`codex`、`claude`、`jiuwenswarm`、`deepseek`。
可选 `dependencies` 将插件 ID 映射到精确版本，例如 `{"studio-brief": "1.0.0"}`。

技能需要 YAML frontmatter，含一致的 `name` 和非空 `description`。包内不能有额外或嵌套的
`SKILL.md`，不区分文件名大小写。模板和脚本放在
该技能目录内，执行时复制到当轮原生技能目录；包内其他文件仅保留，不作为技能资源暴露。
通过现有 `opendirector` CLI 或业务工具发布产物，遵守命令 ID、版本检查、锁与回执。
不要另建可独立编辑的工程副本，也不要直接修改工程 JSON。

开发时可以安装目录。分发时压缩目录的**内容**，确保清单位于 ZIP 根目录，再通过
「选择 ZIP 文件」或公开 HTTPS URL 安装。每包最多 256 个文件／压缩条目，单文件 2 MiB，
解压后总计 20 MiB，压缩包 10 MiB，技能文本 64 KiB。拒绝链接、特殊文件、加密压缩包、
歧义或越界路径、内网下载地址，以及 URL 中的登录凭证；重定向目标同样检查。

维护官方示例时，修改 `packages/agent/plugin-examples/`，在安装项目 Python 依赖的环境运行
`python scripts/package-plugin-examples.py`，一并提交生成的 `plugins/catalog.json`
和 `plugins/examples/` ZIP。发现目录固定包内容摘要，安装时校验。
