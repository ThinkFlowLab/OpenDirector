# Authored basketball starter pack / 原创篮球入门素材

**These are authored teaching illustrations, not AI-generated results.** Created on 2026-11-08 with the reproducible Pillow drawing and FFmpeg encoding script at `scripts/starter-guide/generate.py`. No model, account, key, network, or paid service is used. No photographs, music, game footage, third-party art, or font files are included.

**这些是代码绘制的教学插画，不是 AI 推理结果。** 2026-11-08 制作，使用仓库内脚本与 Pillow / FFmpeg 可重建。无模型、账户、密钥、网络调用或付费服务；未使用照片、音乐、游戏画面、第三方美术或字体文件。

Narrative: an older amateur basketball player pauses, regains focus, and takes one more shot. Inspired only by the comeback storytelling lesson in the README's *We Can Still Win* example; **not an excerpt, reconstruction, or reproduction of that film**. No permission to redistribute the original film or soundtrack is claimed.

叙事：一位年长篮球爱好者停下来、重新专注、再次投篮。只借鉴 README 示例《我们还能赢》的“再次尝试”叙事主题，**不是原片节选、复刻或原片素材**，不声明拥有原片与原音乐的再分发许可。

## Files / 文件

- `shot-1.mp4`: pause / 暂停，4 seconds
- `shot-2.mp4`: focus / 专注，4 seconds
- `shot-3.mp4`: shoot / 投篮，4 seconds
- `shot-1.png`, `shot-2.png`, `shot-3.png`: keyframe illustrations / 镜头关键帧
- `shot-2-alternative.png`: different authored composition / 另一构图候选
- `character-reference.png`, `court-reference.png`: authored references / 人物与场景参考
- `reference-cut.mp4`: 12-second preview of the three clips in default order; **not a replacement for exporting the user's edited timeline** / 默认顺序的 12 秒参考片，不替代用户自己编辑后的时间线导出

All video: 960×540, 24 fps, H.264, yuv420p, silent. Frames are entirely rendered from vector drawing primitives. The character is fictional. Editing prompts does not change the included illustrations or videos. Image-candidate adoption does not regenerate the video clip.

视频均为 960×540、24 fps、H.264、yuv420p、无声，人物虚构。修改提示词不会改变这些预制插画或视频，采用不同图片候选也不会重新生成视频。
