# 换人

> 英文任务请阅读 [SKILL.md](SKILL.md) 及其英文子文档。

**[提示词最高原则](prompt-writing.zh.md#最高原则)**：写清哪个源人物对应哪张肖像、要换哪些特征，表演、镜头和场景交给源片，关键遮挡只用一句话说明谁挡在谁前面。

## 按任务选择路径

- **复用示例分组。** 编辑前先读回示例的分组。逐字沿用提示词，保留引用顺序与素材版本、模型参数、导帧、裁切和音轨策略。在目标项目绑定等价素材，启动前回读保存的配置并对照。遇到不支持的字段时，先指出差异。
- **重试分组中的单段。** 读取目标分组、目标段及受影响的接缝。按[检查结果与重试](workflow.zh.md#检查结果与重试)做单段候选重抽，并核验本次要求。
- **从新素材规划。** [检查项目和模型](workflow.zh.md#1-选择项目和模型)，再[规划源片区间](video-segment.zh.md)和[编写 Ref2VA 提示词](prompt-writing.zh.md)。源片段保留原声供生成参考。

新素材须先用源片检查记录、实际片段和保存后的绑定[通过换人预检](workflow.zh.md#发布并核对计划)。

生成前[发布分组并核对画布上的可见计划](workflow.zh.md#发布并核对计划)。获得生成授权后，[启动已发布的分组并检查输出](workflow.zh.md#3-运行分组并检查输出)。只要求计划或提示词时，交付对应内容。排查效果退步或决定是否重试时，读[失败教训](pitfall.zh.md)。
