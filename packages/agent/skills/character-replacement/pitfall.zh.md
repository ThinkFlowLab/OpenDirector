# 失败教训

| 失败表现 | 处理方式 |
| --- | --- |
| 重建可用的分组时一次改了多项设置，导致无法判断是哪项改动造成效果退步。 | 编辑前先读回示例的分组。提示词、素材版本、模型参数、导帧和裁切区间中，凡不在本次修改范围内的设置均保持原样。 |
| 整片重跑看不出哪项改动有效，还会把做对的镜头改坏。 | 取最小失败区间，对照源片和上一版可用结果。固定其他输入，每次只改一项，提交前明确验收标准。只需单段换种子重抽时直接用 `group regenerate-run-step` + `group adopt-run-candidate`；需要改输入时先局部验证，通过后再跑整片。 |
| 提示词复述分镜或罗列道具，生成结果出现构图拉宽、多余人物和虚构道具。 | 提示词聚焦外观替换。确认有前景物件遮住替换区域时，只写一次遮挡关系。启动前核对保存的提示词和肖像顺序。 |
| 切点放晚，或长动作整段无导帧生成，出现动作错拍或重复。 | 逐帧检查切点两侧。范围外画面直接保留源帧，必要时在稳定姿势处拆分长动作。以源片核对供帧和受帧索引，再播放成片检查接缝。 |
| 模型任务失败，画布上看起来像点击没生效。 | 改配置或重试前，先查分组回执、失败步骤和模型任务 ID。模型列表能打开，推理进程仍可能不可用。 |
| 脸已接近肖像，耳后到颈侧却残留源人物的长发。自然佩戴的配饰容易分散注意力。 | 按源人物轨迹逐项检查替换范围。即使脸部及格，清楚可见的原发残留仍算漏换。配饰按用户要求及佩戴、运动是否自然判断。裁掉或被挡住的部位标待复核。 |
| 追加一句要求完整覆盖发型，输出仍在同一处残留原发。 | 从基线原文出发，只替换一处现有措辞验证一个假设，其余提示词和输入保持原样，复查同一人物、同一帧。 |
| 把动作描述笼统改成「沿用源片」后，特写丢了前景遮挡。 | 有物件经过替换区域时，只保留一句已核实的前后关系。动作和时机由源片提供，检查切点两侧的对应帧。 |
| 连续长镜头作为一次生成提交，后半段动作走样。 | 发布前按实际送入模型的帧数核对约 5 秒的窗口，在稳定姿势处分段，用导帧续接。 |
| 把开场站位套到后续近景，导致人物标错或绑错肖像。 | 沿源片用确认帧追踪同一人物，发布前核对标题、提示词和实际肖像引用。 |
| 冻结或循环补齐短片段，或在人物不完整时拆段，导致动作或换人质量下降。 | 向后截取真实源片补足窗口，在待替换区域清楚可辨的稳定帧拆段，组装时裁去多取的上下文。 |
| 锚点漏掉分段字段，触发普通视频参考数量校验。 | 锚点保存空的 `h3Segment`，回读后检查固定源视频，再判断部署能力。 |
| 锚点从手和手机的插镜起跑，片尾单帧又被并入了人物特写。 | 查看实际解码的首帧、末帧及切点两侧。把插镜独立列为原片直通，选可辨认的人物帧做锚点。用同一检查记录生成提示词，并回读肖像版本和导帧索引。 |
| 开启 Swap LoRA 后，人物外观可以换对，但口型可能与源对白错位。 | 组装前后都对照同步的源音轨检查清楚可见的对白口型。如果生成片段本身已不同步，只关闭 Swap LoRA 重跑受影响的片段，固定 Turbo、seed、提示词、参考素材和源片区间。 |
| 用连续原片和同步原声把短对白特写补到与输出等长，仍未修复口型。后续双人镜头提前出现，抽查帧里的目标人物仍未替换。 | 输入输出等长用于满足生成长度要求。验收口型时，用原对白区间的对应帧和原声核对镜头、说话人、替换结果和嘴部动作。切镜或说话人跑偏时，拒绝采用该候选，调整输入方案后再试。 |
| 提示词明确了对白归属，后段主要由正确的人动嘴，但原片的单人特写仍被延续成双人镜头。 | 依次核对原切点与构图、说话人轨迹、口型与原声的时序。切镜缺失就拒绝采用。若保留切镜的文字约束已经试过，停止追加同类描述，另做单变量的视觉约束测试。 |

## One-shot 对照：双人镜头切到单人对白特写

源片从两人同框切到其中一人的对白特写。两条镜头映射已核实，后段说话人是 `<Subject 2>`。多镜头片段由模板在 `detailed_description` 的镜头映射后自动加上保留切镜的句子。做对照时固定有声源片、肖像顺序、模型、采样和声音说明，只比较这一句：

```diff
 [Shot 1] <Subject 1> -> <Picture 1>, <Subject 2> -> <Picture 2>.
 [Shot 2] <Subject 2> -> <Picture 2>.
+Preserve the original cut between these shots in <Video 1>.
```

这是用于验证切镜的对照写法。若仍丢切镜，本轮判失败。若切镜和说话人都正确、只有口型错位，下一轮只改 `overall_soundscape`，明确该人物的嘴部动作与 `<Video 1>` 中同一人物的原对白同步。

- 对白绑定可以写对说话人，成片仍可能漏掉源切镜。先对比源切点前后的画面，再判断口型。源片进入单人特写后如果生成结果仍是双人镜头，先拒绝该候选，再决定如何继续。 固定源片、肖像顺序和种子后，单独把声音说明改为明确的说话人绑定，两次候选仍都漏掉切镜。改用结构化的镜头和说话人绑定后，切镜仍未恢复。切镜通过后再验收口型。

固定输入、模型和种子，只把切镜句改为明确切到源片单人镜头，仍然漏切镜。两种写法都漏掉同一个硬切时，下一步用独立生成窗口和固定交付切点验证。

扩大真实输入窗口后，硬切可能恢复，但特写仍保留原人物。分别验收切点帧和换人覆盖，看到切镜还不能判定通过。

候选把肖像照生成成画面时，先只试结构化 `portraitAppearanceOnly` 约束。一次固定引用、种子和采样的对照中，这恢复了两条人物替换，并保住保留区的源片构图。扩展到其他段前，核对完整保留区和交付接缝。

肖像用途约束能修复参考图串入，但后续镜头仍可能漏换。多镜头窗口只换对开场时，逐个核对切点两侧的人物替换和时序。先为漏换的交付区间验证独立生成窗口。

倒序窗口即使从目标特写起跑，恢复正序后也可能在整个保留区生成相邻双人镜头。按实际裁切恢复正序再审片。如果已有正向窗口能保住特写，优先验证该窗口并按原切点裁切，再决定是否改对白措辞。

固定输入的对照中，`completeHairReplacement` 改变了部分抽帧的嘴形，但耳后和后颈仍残留源人物长发。该措辞尚未证明有效，采用候选前分别检查发型轮廓和嘴部动作。

固定输入改为明确露出耳朵和颈部，仍残留长发轮廓。两种措辞均失败后，保留最好的候选，下一步验证视觉参考能否控制轮廓。

固定首帧图片导帧可以修正持续的发型残留，但口型仍可能偏离。固定其他输入，将有无导帧的候选与原片保留区间对齐比较。即使头部外观替换完整，只要原说话人的口型时序明显偏移，就先不采用候选。

固定源片、肖像、首帧导图和种子后，把说话人绑定句换成逐帧跟随嘴部动作的指令，改变了生成嘴形，但仍有可见的口型错位。这条措辞只用于试验。音轨对齐不能证明嘴部动作对齐。

跨多个切镜的倒序输入即使含有正确的保留画面，生成结果也可能在该区间串入别的镜头。按发布配置反转并裁切，再与正序源片同帧对照。确认输入窗口正确后，优先试验用应保留镜头的画面做锚定。

固定倒序窗口的对照中，用计划保留镜头的输入第 0 帧制作图片导帧，保住了交付区间内的近景。导帧槽位按生成播放顺序确定，结果按成片顺序检查。

开场镜头的图片导帧可以恢复丢失的特写，后续硬切仍可能偏移一帧。核对源片切点前后的相邻输出帧，确认切点时序。

续接可能把导帧里的遮挡手持续留在画面中，即使源片的手已经离开。要同时检查保留区间开头和后段的前景道具、身体部位和动作。导帧位置与人物对应正确，也要验收动作。

固定源片和 0/21 导帧后，加模板的前景遮挡句仍没有消除滞留的手套。用该字段表达遮挡层次。同条件复测后若滞留依旧，先隔离包含旧姿态的导帧，再决定是否改措辞。

Goodnight try0086 的 C2 只保留 C1 第 102 帧作为输出第 0 帧导图，白手套仍在原片退场后滞留在右侧。单导帧和双导帧均未通过同帧检查。测试明确描述原片退场的措辞时，固定导帧。

MiniMax 官方 PE 将 C2 的白手套写成先降出画面，再进入后面的指向动作。完整改写还加入了独立的 <Audio 1> 标签和大量对白、场景细节。将看得见的手套退场动作作为单变量措辞候选，使用完整改写前先核对实际请求的参考标签。

Goodnight try0086 的 C2 改成随原片退场后，右侧白手套仍滞留。11 张同帧对照表明泛写退场未修正动作。先固定导帧，复测 PE 提出的手套下移写法，再决定是否推广。

try0086 的 C2 用官方 PE 提取的下移措辞后，成片哈希改变，但抽查第 381–438 帧仍见右侧抬起的手套。两种退场措辞在相同的 C1 第 102 帧导图下均失败。对照 C2 自身开头的导图时，固定源片窗口和交付裁切。

try0086 C2 换成基于自身开头制作的第 0 帧固定导图后，11 张同帧抽查中手套能退场，后续指向动作也保住了。仅更换 PE 措辞而沿用上游导帧时仍会滞留。C1→C2 接缝还有面部光色跳变，验收本段锚点时要查看接缝两侧的连续帧。

Goodnight try0086 的 C3 从卧室段续接后保住了指向动作，但原片第 484 帧切到亮房舞蹈时，生成仍留在卧室。第 532–548 帧抽查中，棕发单人也漏换。为亮房舞蹈和漏换的单人特写使用独立生成窗口，保持原片切点，组装前分别核对切镜和换人覆盖。

try0086 亮房双人舞拆成独立倒序窗口后恢复了亮房场景，但交付区间的舞步仍有偏移，且保留了原人物的发型轮廓。按发布配置反转和裁切后，分别核对动作与两人换人覆盖。改变交付边界前，先试实际生成输入第 0 帧的同构图换人导图。
